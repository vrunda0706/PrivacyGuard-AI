# 🛡️ PrivacyGuard AI

### AI-Powered Personal Data Exposure Monitor

PrivacyGuard AI is a privacy-focused web application that analyzes potential personal-data exposure and generates a **privacy risk score**, **AI-based risk classification**, and **personalized security recommendations**.

The project combines **Python, Flask, SQLite, JavaScript, and Machine Learning** to demonstrate how AI can be applied to cybersecurity and privacy monitoring.

> ⚠️ **Important:** This portfolio version uses simulated exposure findings. It does not connect to real dark-web, breach, or leaked-data databases and does not collect passwords or OTPs.

---

## 🚀 Features

- 🔍 Personal data exposure analysis
- 📊 Privacy risk score
- 🤖 Machine-learning based risk classification
- 🛡️ Personalized security recommendations
- 📱 Permission risk analyzer
- 🗃️ Scan history using SQLite
- 📈 Risk visualization with charts
- 🌐 Flask REST API
- 💻 Responsive cybersecurity dashboard
- 🔒 Privacy-focused design
